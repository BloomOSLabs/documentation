# Frequently Asked Questions

## Is this an official BloomOS device?

Yes.

The OPPO A31 (OP4C7D) is officially supported by BloomOS.

---

## Will installing BloomOS erase my data?

Yes.

Unlocking the bootloader and performing a factory reset removes all user data.

Always create a backup beforehand.

---

## Can I update without reinstalling?

Official releases will support OTA updates whenever possible.

If manual installation is required, release notes will provide the necessary instructions.

---

## Can I return to stock firmware?

Yes.

You can restore the official firmware using the manufacturer's flashing tools.

---

## Is root included?

No.

BloomOS does not include root access.

Users who require root may install a supported root solution after installation.

---

## Is Google Apps included?

This depends on the specific BloomOS release.

Refer to the release notes for the version you are installing.

---

## I found a bug.

Please report reproducible issues through the official GitHub issue tracker with logs whenever possible.
