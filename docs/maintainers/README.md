# Maintainer Documentation

This section is intended for official BloomOS device maintainers.

Topics include:

* Device bring-up
* Vendor blobs
* Kernel integration
* SELinux
* AVB
* OTA configuration
* Release process
* Documentation standards

## Responsibilities

Official maintainers are expected to:

* Verify every release before publication.
* Keep device documentation up to date.
* Respond to reproducible bug reports.
* Maintain a stable installation experience.
* Submit changes through GitHub pull requests.
