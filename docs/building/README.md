# Building BloomOS

BloomOS is built entirely from source using the Android Open Source Project build system.

## Requirements

Typical requirements include:

* Linux development environment
* Git
* Repo
* Java Development Kit
* Android Platform Tools

## Build Workflow

The standard workflow is:

1. Initialize the source tree.
2. Synchronize repositories.
3. Configure the build environment.
4. Select a device.
5. Compile BloomOS.
6. Sign and distribute builds.

Device-specific bring-up documentation is maintained separately.

See the Maintainers documentation for more information.
