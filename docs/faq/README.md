# Frequently Asked Questions

## What is BloomOS?

BloomOS is an open-source Android operating system focused on privacy, security, performance and long-term maintainability.

---

## Is BloomOS free?

Yes.

BloomOS is completely free and open source.

---

## Does BloomOS include Google Apps?

This depends on the specific release.

Refer to the release notes and device documentation.

---

## Can I root BloomOS?

Yes.

BloomOS itself does not include root access, but supported root solutions may be installed after installation.

---

## How do I report bugs?

Open an issue on the official GitHub repository with:

* Device name
* BloomOS version
* Steps to reproduce
* Relevant logs

---

## Where can I get support?

Support is available through:

* GitHub Issues
* Official Telegram community
* Device maintainers
